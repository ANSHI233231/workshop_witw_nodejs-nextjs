# Roles

One file per role: who they are, which app they use, what they can do, what they cannot do, and who creates or manages them.

| Role | App | Summary |
|---|---|---|
| [Super Admin](super-admin.md) | manage | System role 100: every console page and every Super Admin API route |
| [Partner](partner.md) | partner, web | System role 101, given when a partner request is approved: their own packages, galleries and quote requests in the Partner portal |
| [Website user](website-user.md) | web | An account with no role: shared safaris, quote requests, Become a Partner |
| [Guest](guest.md) | web | Not signed in: browses shared safaris, packages and parks |
